# Dataset de prueba de delitos

Dataset inicial de 20 registros seleccionado a partir del archivo de datos disponible para pruebas.

## Características
- 20 registros.
- Incluye variación de clasificación, grupo/subgrupo, lugar y rango horario.
- `fuente` se establece como `SIED-CEAD`.
- Este archivo es un dataset de entrada de prueba y no corresponde todavía al modelo interno normalizado de Supabase.

## Campos
- `fecha`
- `rango_horario`
- `clasificacion`
- `familia_delitos`
- `grupo_subgrupo_delitos`
- `lugar`
- `comuna`
- `latitud`
- `longitud`
- `fuente`
- `estado_coordenadas`
