## 1. Objetivos y requerimientos relacionados

| Objetivo | Descripción resumida |
|---|---|
| OE-1 | Procesar, almacenar y analizar datos delictuales georreferenciados para utilizarlos en mapas de calor y rutas. |
| OE-2 | Representar las zonas de riesgo mediante mapas de calor. |
| OE-3 | Generar rutas peatonales que consideren el riesgo y eviten zonas de alto riesgo. |
| OE-4 | Desarrollar la interfaz móvil para consultar mapas, rutas y filtros de seguridad. |

| Requerimiento | Descripción resumida | Objetivo relacionado |
|---|---|---|
| RF-01 | Consultar y procesar datos delictuales georreferenciados. | OE-1 |
| RF-02 | Obtener y disponer de una red peatonal georreferenciada. | OE-1, OE-3 |
| RF-03 | Calcular y clasificar zonas/segmentos según su riesgo. | OE-1, OE-2, OE-3 |
| RF-04 | Visualizar delitos y zonas de riesgo en el mapa de calor. | OE-2, OE-4 |
| RF-05 | Filtrar la información por rango horario. | OE-2, OE-4 |
| RF-06 | Obtener y visualizar la ubicación actual del usuario. | OE-4 |
| RF-07 | Buscar una dirección y centrar el mapa en el resultado. | OE-4 |
| RF-08 | Seleccionar y modificar origen y destino. | OE-3, OE-4 |
| RF-09 | Generar rutas alternativas considerando riesgo y distancia. | OE-3 |
| RF-10 | Mostrar geometría, distancia, tiempo y métricas de riesgo de las rutas. | OE-3, OE-4 |
| RF-11 | Interpretar las alternativas mediante el servicio de IA. | OE-3 |
| RF-12 | Utilizar las funcionalidades principales desde la aplicación móvil. | OE-4 |

> Los IDs RF/RNF se conservan según la estructura de requerimientos trabajada para RutaSegura. Antes de cerrar la versión del repositorio, cotejar los nombres y asociaciones con el archivo vigente `docs/requerimientos.md`, especialmente si ese archivo tuvo cambios posteriores.

## 4. Trazabilidad de riesgos

| Riesgo | Qué amenaza | Objetivo / requerimiento afectado | Mitigación o respuesta registrada | Estado real |
|---|---|---|---|---|
| R-01 — Coordenadas no asociadas individualmente a cada delito | Integridad espacial del análisis y localización de las zonas. | OE-1, OE-2; RF-01, RF-03, RF-04. | Asociación uno a uno entre registros delictuales y coordenadas, dejando documentado el supuesto. | Mitigado parcialmente: permite operar con los datos disponibles, pero la validez del supuesto sigue siendo una limitación. |

| R-03 — Metodología de cálculo de riesgo no validada externamente | Validez e interpretación de puntajes, zonas y rutas recomendadas. | OE-1, OE-2, OE-3; RF-03, RF-04, RF-09. | Mantener el modelo propio de RutaSegura como contingencia e intentar obtener la metodología oficial. | Abierto como riesgo residual: no se recibió confirmación de la fórmula oficial; el modelo no debe atribuirse a Carabineros/SIED. |
